# Om Sharma — Cute Dark + Pink Portfolio

Plain HTML, CSS and JavaScript. No install, no server needed.

## Run locally
Open `index.html` in a browser (or use VS Code Live Server).

## Add your contact links (important)
Open `script.js` and fill the CONFIG at the top:

    const CONFIG = { email: 'you@gmail.com', github: 'https://github.com/you', linkedin: 'https://linkedin.com/in/you' };

Empty values keep that button hidden, so nothing is ever broken.

## Edit skill levels
In `index.html`, change `data-level="1..5"` (hearts) on each skill card.

## Put it online (free)
- **Netlify Drop**: go to app.netlify.com/drop and drag this folder in.
- **GitHub Pages**: upload the 4 files to a repo -> Settings -> Pages -> Deploy from `main` / root.
